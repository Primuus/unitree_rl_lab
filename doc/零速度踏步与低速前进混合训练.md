# 零速度踏步与低速前进混合训练

2026-10-31 用户确认实施。当前 `balance` 入口改为混合命令训练；已有 12 动作模型继续使用，不创建并存版本。本轮只修改和验证，未启动 PPO 训练。

## 当前设置

| 项目 | 配置 |
| --- | --- |
| 训练入口 | `scripts/train_v20.py --stage balance --resume <checkpoint>` |
| 零速度概率 | 每环境、每次重采样 50%，三个命令分量严格为零 |
| 前进概率 | 50%，前进速度均匀采样 0.05～0.10 m/s |
| 横向、转向 | 0 |
| 重采样 | 每 10 秒以及环境重置时；同一环境可经历启停 |
| 采样实现 | Isaac Lab 原生 UniformVelocityCommand；heading_command=False |
| 相位 | 零速度和前进时始终提供 sin/cos，周期 1.6 s，不因命令切换重置 |
| 抬脚 | 脚底目标峰值 6 cm，20% 双支撑 |
| 奖励 | 两种命令均使用现有 27 项；不增加奖励、不另调权重 |
| 速度跟踪分母 | 线速度 0.0025、角速度 0.04，跟踪每个环境自己的命令 |
| 控制和 PPO | 保持现有配置；续训恢复优化器及自适应学习率标量 |
| 自动速度扩展 | 尚未启用，先评估当前范围，再决定是否扩展 |

50% 是概率，不保证每批恰好各一半。命令采样不同于关节动作采样；策略仍输出 12 维关节动作。允许零命令下原地踏步，继续约束累计位移和航向漂移。

`walk` 保留为固定前进 0.2 m/s 的入口，但奖励、相位与混合训练统一，不再切回旧 23 项奖励及 0.25 跟踪分母。下一轮建议使用 `balance` 混合续训，当前不需要切换到 `walk` 训练。

## 评估方式

训练和评估分别配置命令。评估不继承训练的 50% 概率：balance 强制全体零命令，walk 强制全体指定前进速度。旧 checkpoint 的相位模式仍从 provenance 恢复；新训练 provenance 保存 always 模式与实际命令分布。

分别评估零速度、0.05 m/s、0.10 m/s：

```bash
./ry_python.sh scripts/eval_v20.py --stage balance --checkpoint <checkpoint> \
  --num_envs 16 --steps 1000 --out logs/evaluation/mixed_zero --headless --device cuda:0
./ry_python.sh scripts/eval_v20.py --stage walk --speed 0.05 --checkpoint <checkpoint> \
  --num_envs 16 --steps 1000 --out logs/evaluation/mixed_forward005 --headless --device cuda:0
./ry_python.sh scripts/eval_v20.py --stage walk --speed 0.10 --checkpoint <checkpoint> \
  --num_envs 16 --steps 1000 --out logs/evaluation/mixed_forward010 --headless --device cuda:0
```

零速度继续用 stationary-v2 验收，同时查看有效落脚和交替率；行走单独查看速度误差、前进位移、抬脚和交替。两类结果不合并为一个平均奖励。现有行走验收与站立验收不同，偏航指标也应单独查看。本轮未修改验收阈值，也没有把短时配置检查当作策略能力验收。

## 本轮验证结果

- 本机与服务器：18 项奖励/配置/相位回归、7 项验收指标回归通过。
- 对服务器安装版本的原生命令采样方法做 100000 次样本检查，seed=1：零命令 50106，前进 49894，前进均值 0.07508018 m/s；范围与横向/转向零约束通过。
- Isaac Lab 64 环境，加载 model_6988.pt，仅推理 32 控制步。命令经理完成后处理后的初始分布 32 零命令 / 32 前进；触发实际重采样计时器后为 34 / 30，11 个环境停止转前进、13 个环境前进转停止，计时器恢复 10 s。
- Actor/Critic 为 56/155，动作 12，活动奖励 27。相位在两种命令下保持有效，观测和奖励均为有限值。恢复学习率 5.0625e-5，优化器更新次数为 0。
- 短时检查只验证配置和执行链路，不代表混合训练已经收敛。首个检查在命令后处理前读取采样缓冲而失败，调整测试读取时机后通过；未因此修改工程采样器。
- 服务器保留检查日志及 JSON：logs/evaluation/mixed_command_config_smoke_20261031.{log,json}。本轮临时检查脚本已清理，正式运行不依赖它。
