# 代码来源说明

本仓库的 v20 代码及公共基础代码来自原 Unitree RL Lab 工作区，复制来源、变更后的路径和 SHA256 记录于 `dependency_migration_manifest.json`。独立工作区中的导入路径、任务名和入口已按本工程调整。

基础执行器/机器人配置和训练接口沿用 Isaac Lab 相关实现。原文件中的版权和 SPDX 声明予以保留；Isaac Lab 原有 BSD-3-Clause 许可文本复制于 [third_party/IsaacLab_LICENSE](third_party/IsaacLab_LICENSE)。

外部参考项目：

- Isaac Lab：<https://github.com/isaac-sim/IsaacLab>
- Unitree ROS：<https://github.com/unitreerobotics/unitree_ros>

双足 URDF 为原工程已有资源；本次未重新生成机器人模型。`unitree_ros` 的外部网格不随本仓库重复提交。
