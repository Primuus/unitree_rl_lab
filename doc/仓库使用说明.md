# 仓库使用说明

当前任务已经在原 V20 位置直接覆盖为 12 关节后腿直立训练实现。后续直接修改当前代码，不建立版本副本。任务 ID 仍为 `RY-Unitree-Go2-Biped-Gait-v20`，现有文件名只保留入口兼容。

运行环境为 `isaac-record` 容器中的 `/workspace/ry_unitree_rl_lab`。外部工程依赖为 `/workspace/isaaclab` 和 `/workspace/unitree_ros`，不依赖原 `/workspace/unitree_rl_lab`。

当前验证环境沿用 Isaac Lab 2.2.0、Isaac Sim 5.0.0-rc.45、Python 3.11、PyTorch 2.7.0+cu128、RSL-RL 2.3.3。

完整的参数、阶段、运行命令与适配差异见 [当前 12 关节训练说明](V21_参考My_unitree_go2_gym的后腿步态优化方案.md)。

正式训练默认使用 4096 个并行环境，可通过 `--num_envs` 覆盖。短训练示例使用 64 个环境：

```bash
./ry_python.sh scripts/train_v20.py --stage balance \
  --num_envs 64 --max_iterations 3 --run_name smoke \
  --headless --device cuda:0
```

训练产物位于 `logs/rsl_rl/ry_unitree_go2_handstand/`，包括 checkpoint、参数、来源快照与 `exported/policy.pt`、`policy.onnx`。训练后可用 `--resume` 恢复结构一致的 12 动作权重，再指定 `--stage walk` 继续训练。`balance` 使用三轴零命令和 21 项奖励；`walk` 固定前进 `0.2 m/s`、横向和转向为零，使用 23 项奖励。独立评估的默认前进速度同步为 `0.2 m/s`。

旧的 6 动作权重和过往实验记录继续保留；不作为当前训练初始化来源。训练和 Isaac Lab 评估在服务器容器进行；本机 MuJoCo 观看入口见 [MuJoCo 部署说明](MuJoCo部署说明.md)。

[验证报告](V21_实现与验证.md)记录本轮实际运行结果。训练、评估输出和生成模型不纳入 Git。

站立平衡训练 1000 轮、每 50 轮保存 checkpoint：

```bash
./ry_python.sh scripts/train_v20.py --stage balance \
  --num_envs 4096 --max_iterations 1000 --save_interval 50 \
  --run_name stage1_balance_1000 --headless --device cuda:0
```

`--save_interval` 仅覆盖本次运行的保存间隔；不传时沿用参考配置的 100 轮。checkpoint 留在本次训练目录，需要时通过 `scripts/eval_v20.py --stage balance --checkpoint <checkpoint路径>` 查看。
