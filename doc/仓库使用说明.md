# 仓库使用说明

仓库：<https://github.com/Primuus/unitree_rl_lab>。任务：`RY-Unitree-Go2-Biped-Gait-v20`。

## 环境

在已有 Isaac Lab 和 Unitree ROS 资源的容器中使用：

- `/workspace/isaaclab`：当前验证版本为 Isaac Lab 2.2.0、Isaac Sim 5.0.0-rc.45。
- `/workspace/unitree_ros`：含 `robots/go2_description` 网格资源。
- 当前验证的运行库：Python 3.11、PyTorch 2.7.0+cu128、RSL-RL 2.3.3。

无需安装或保留原 `/workspace/unitree_rl_lab` 工程。本仓库通过 `ry_python.sh` 加载自己的模块，Python 库复用现有容器环境。

在新环境的 `/workspace` 中克隆并启动：

```bash
git clone https://github.com/Primuus/unitree_rl_lab.git ry_unitree_rl_lab
cd ry_unitree_rl_lab
./ry_python.sh scripts/train_v20.py \
  --warm_start_actor checkpoints/warm_start_v11_model_40.pt \
  --num_envs 64 --max_iterations 10 --run_name demo \
  --seed 42 --headless --device cuda:0
```

这是基于已有 Actor 的短训练示例。正式训练可调整环境数和迭代数，运行前检查 GPU 空闲情况。当前入口要求提供热启动权重，Critic 与优化器重新初始化。

## 输出与评估

训练结果保存在 `logs/rsl_rl/ry_unitree_go2_biped_walk_v20/<时间_实验名>/`，包括 checkpoint、环境/算法配置、代码来源记录，以及 `exported/policy.pt` 和 `exported/policy.onnx`。

评估时将下面的路径替换为本次训练生成的 checkpoint：

```bash
./ry_python.sh scripts/eval_v20.py \
  --checkpoint logs/rsl_rl/ry_unitree_go2_biped_walk_v20/<时间_实验名>/model_9.pt \
  --num_envs 4 --steps 1000 --speed 0.12 --seed 42 \
  --out logs/evaluation/demo --headless --device cuda:0
```

训练默认前向命令为 0.12 m/s，示例评估显式使用相同速度。评估器自身默认速度仍为 0.2 m/s。

## Git 管理范围

提交源码、双足 URDF、说明和验证记录，以及运行必需的 `checkpoints/warm_start_v11_model_40.pt`。训练/评估输出、其他权重和导出包保留在运行目录中，不提交。

文档中的旧实验路径用于记录当时的运行位置。实际环境依赖、当前命令和模块结构以本说明及 `V20副本说明.md` 为准。
