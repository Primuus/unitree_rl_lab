# 仓库使用说明

当前任务为完整 Go2 的 12 关节后腿直立训练，稳定入口为 RY-Unitree-Go2-Biped-Gait-v20、scripts/train_v20.py 和 scripts/eval_v20.py。代码直接覆盖当前实现，模型和实验记录保留。

2026-10-31 用户批准恢复参考工程 go2_handstand 的全部 23 项奖励，进行从零训练对照。当前公式、权重及门控来自仓库内固定来源快照，已撤掉此前新增的欠抬脚、滑移、零转向和航向保持奖励。旧的 27 项奖励及高度收紧实验属于历史记录，不代表当前配置。详见[恢复参考奖励对照](参考奖励恢复与从零训练对照.md)和[当前参数](V21_参考My_unitree_go2_gym的后腿步态优化方案.md)。

运行位置为服务器 isaac-record 容器 /workspace/ry_unitree_rl_lab；依赖 /workspace/isaaclab 和 /workspace/unitree_ros，不依赖原 /workspace/unitree_rl_lab。已验证环境为 Isaac Lab 2.2.0、Isaac Sim 5.0.0-rc.45、Python 3.11、PyTorch 2.7.0+cu128、RSL-RL 2.3.3。

本轮从零训练 1000 轮，4096 环境、单卡、每 50 轮保存：

```bash
./ry_python.sh scripts/train_v20.py --stage balance \
  --num_envs 4096 --max_iterations 1000 --save_interval 50 \
  --run_name reference_rewards_scratch1000 --seed 1 --headless --device cuda:0
```

不传 --resume；不使用旧 6 动作或旧 12 动作权重。balance 保留 50% 零速度、50% 前进 0.05～0.10 m/s 混合采样，每 10 秒及重置时重采样，横向和转向为零。walk 保留固定前进 0.2 m/s。两个入口均为同一套参考奖励。

本轮固定当前直立初始化、Actor56/Critic155 观测和混合命令，以检验恢复奖励的影响。这些仍不同于参考工程完整训练条件，不能将本轮称为完整复现。

训练产物位于 logs/rsl_rl/ry_unitree_go2_handstand/，包括 checkpoint、参数、来源快照和策略导出。实际启动及自动评估位置见[本轮记录](参考奖励恢复与从零训练对照.md)。

训练结束后分别评估零速度、0.05 和 0.10 m/s。零速度示例：

```bash
./ry_python.sh scripts/eval_v20.py --stage balance \
  --checkpoint <本轮checkpoint> --num_envs 16 --steps 1000 --seed 1 \
  --out logs/evaluation/reference_zero --headless --device cuda:0
```

前进使用 --stage walk --speed 0.05 或 --speed 0.10。评估强制固定命令，不混合采样；站立按[stationary-v2](站立验收条件.md)验收，步态仍检查合格落脚和持续交替。完整 20 秒内的抬脚峰值需区分初始化瞬态。

旧 checkpoint 评估时当前奖励分数已改变；策略物理表现可比较，不能直接比较跨奖励版本的总奖励。旧运行参数和源码快照继续保留。
