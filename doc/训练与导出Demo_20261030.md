## 复现命令

在容器内执行，重复实验应更换 run_name：

```bash
cd /workspace/ry_unitree_rl_lab
./ry_python.sh scripts/train_v20.py \
  --warm_start_actor /workspace/ry_unitree_rl_lab/checkpoints/warm_start_v11_model_40.pt \
  --num_envs 64 --max_iterations 10 --run_name ry_train_export_demo_new \
  --seed 42 --headless --device cuda:0
```

正式长训练需另行设置迭代次数和环境数，并在运行时检查 GPU 占用。
