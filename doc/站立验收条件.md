# 原地站立验收 stationary-v2

用户要求先补充验收，再进行 6 cm 目标高度的 500 轮续训。本轮因跳板机 SSH 拒绝连接，用户进一步要求先完成验收条件；训练尚未启动，服务器同步与运行验证待连接恢复后完成。训练奖励、PPO、控制参数和 6 cm 目标配置均未修改。

## 统一条件

Isaac 与 MuJoCo 共用 `ry_unitree_rl_lab/utils/balance_acceptance.py`。这些阈值是本项目的工程验收选择，不是参考工程提供的标准。

| 条件 | 判定 |
| --- | --- |
| 模式 | 已加载策略、balance 零命令 |
| 有效时长 | 至少 15 s，常规评估使用 20 s |
| 提前失败 | 0 次；训练当前为 base 接触力超过 1 N |
| 直立比例 | 大于 95%；直立余弦大于 0.94 且基座高度大于 0.43 m |
| 前脚接触比例 | 小于 1% |
| 平均绝对前向速度误差 | 不超过 0.04 m/s |
| 平均绝对世界竖直轴角速度（新增） | 不超过 0.05 rad/s |
| 相对初始方向最大连续航向偏差（新增） | 不超过 15° |
| 相对初始位置最大水平距离（新增） | 不超过 0.20 m |
| 水平路径长度 / 有效时长（新增） | 不超过 0.04 m/s；20 s 对应路径不超过 0.80 m |

每个环境独立判断，所有环境通过才报告总体通过。不能用多个环境的平均值掩盖单个环境失败。连续交替踏步仍是单独指标，不属于本次原地站立验收的必要条件。

## 统计方式

- 航向使用直立机身的水平前向方向（本体 -Z 投影），逐步累加相邻角度的最短有符号差。跨越 ±π 不产生跳变，转满一圈记作约 2π 而不是零。最大偏差检查整个有效过程，不只检查终点。
- 水平路径累加相邻位置间距离；往返运动和绕圈不会因终点靠近起点而抵消。另输出净位移、净航向变化、绝对航向变化总量，辅助区分持续转圈和来回摆动。
- 统计采样周期为策略周期 0.02 s，评估包括初始化过程，不丢弃起始几秒。路径是采样折线长度，不是物理子步上的完整高频轨迹。
- Isaac 在首次结束后停止该环境的计分，排除复位造成的位移和转角；保留结束原因。MuJoCo 在首次检测到 base 接触力超过 1 N 后停止验收计分，窗口继续展示运动，失败标志保留；按 R 手动重置开启新的统计。
- MuJoCo `summary.balance_acceptance` 输出版本、阈值、实测值、逐项布尔结果和 `failed_checks`。原有顶层直立比例等全程摘要保留，判断是否站稳以 `balance_acceptance_passed` 为准。
- Isaac 输出 `balance_acceptance_reports`、`balance_acceptance_per_env` 和 `balance_acceptance_passed`；行走阶段的原验收逻辑保持原样。
- 两引擎共用阈值与判定函数，但接触求解、采样端点和动力学不同，不能据此认为两引擎效果等价。

## 待连接恢复后的续训

先同步本轮代码并执行容器测试，以新标准评估 model_5990 作为基线，再从该权重按 6 cm 目标续训 500 轮：4096 环境、cuda:0、seed=1、每 50 轮保存 checkpoint，训练后用相同的 16 环境、20 s 设置评估。相位接触权重 +0.9、抬脚权重 +1.0，其余奖励保持当前值。本轮没有创建后台训练任务。
