## 抖动诊断

同条件单环境、20 秒；排除前 2 秒，按 5 ms 物理步采样，共 3602 个样本，控制周期 20 ms。

| 指标 | model_3994 | model_4493 |

| 右前髋速度 RMS rad/s | 1.884 | 2.529 |
| 左前髋角度标准差 rad | 0.04582 | 0.05489 |
| 右前髋角度标准差 rad | 0.03724 | 0.05722 |
| 两前髋角度主导频率 Hz | 8.61 | 7.33 |
| 左前髋目标角差分 RMS rad/控制步 | 0.08013 | 0.06935 |
| 右前髋目标角差分 RMS rad/控制步 | 0.07953 | 0.07358 |

主频降低不代表抖动减轻：两前髋角度波动幅度与速度 RMS 均增加，尤其右侧。策略目标角差分下降，但实际关节运动加重，因此仅凭 action_rate 或目标角平滑程度不能判断实际抖动已解决。单环境诊断仍全程直立、无倒地。

诊断同时直接调用 foot_slip 奖励函数，2 秒后原始均值为 0.117741，加权后、乘 dt 前为 -0.058870。该项确实产生惩罚，不是配置未生效。它是接触门控后的双脚瞬时水平速度平方之和，不能用表中平均滑移速度先平方来替代；训练时随机动作下的累计奖励也不能直接与此确定性评估均值比较。

本轮未进行 MuJoCo 回放或下载策略，不能据此声称 MuJoCo 表现已经改善。

## 结论及记录

本轮转动稳定性改善，但漂移、防滑和前髋抖动未改善，不应把 model_4493 当作原地站立性能全面优于 model_3994 的版本。两个模型及全部实验记录保留。后续宜分别处理静止速度约束与前腿运动约束；本轮没有继续调权重或启动额外训练。
