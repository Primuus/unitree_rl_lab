# 混合命令采样与训练设置建议

状态：分析与拟议配置，尚未修改训练代码、奖励权重或启动训练。当前执行配置仍为 `balance` / 固定前向 `walk`。后续实现直接覆盖当前工程，不建立版本副本。

## 1. 参考范围与源码版本

本次查看用户指定的 [Primuus/quadruped_RL](https://github.com/Primuus/quadruped_RL)：

- `main`：部署分支，核对版本 `ac0e6f243fc8b7cb6b4b2601235094e81250a132`。
- `train`：实际训练分支，核对版本 `bdd5efb55adce9d32f1bd1ba85902ed7aff35401`。
- 奖励继续以 `My_unitree_go2_gym/go2_handstand` 为来源；本次借鉴的是命令分布及按模式统计方法。

部署分支部分文档描述七模式、速度课程和命令过渡；所读训练分支的 Primuus 源码实际为五模式、固定范围、每 5 秒直接切换，`commands.curriculum=False`。部署侧的 `CommandReference` 也不能视为该训练分支已接入相同参考。本建议以固定版本的可执行训练源码为依据。

## 2. 可以直接借用的设计

| 项目 | Go2 训练配置 | Primuus 训练配置 |
| --- | --- | --- |
| 模式 | 原地转向、边走边转、平移、站立 | 同前四类，另加独立纯前进 |
| 比例，按源码顺序 | 25%、25%、30%、20% | 20%、15%、25%、20%、20% |
| 重采样 | 每环境每 5 秒，以及重置时 | 同左 |
| 转向控制 | 直接采样 yaw rate | 同左 |
| 站立命令 | 三轴全零 | 同左 |
| 平面速度 | 限制 XY 合速度 | 平移/边走边转限幅，纯前进独立范围 |
| 额外覆盖 | 30% 低速子集 | 平移中 60% 轴向采样，纯前进分段采样 |

推荐借用 Primuus 五模式结构。独立纯前进避免连续 XY 采样几乎抽不到严格的 `vy=0, yaw=0`；轴向分支保证后退和纯侧移有明确样本。所有环境共用同一策略，各环境独立抽取命令模式。

这些模式是速度命令类别；关节动作依然由 PPO 根据状态和命令进行连续高斯采样。保留当前 12 动作、Actor 56 / Critic 155 维和 50 Hz，不迁移该四足项目的 HIM-PPO、270 维历史输入或机器人动力学。

## 3. 建议的最终混合分布

保持参考代码的实现顺序：

```text
mode_names = (turn, moving_turn, translate, stand, forward)
mode_probabilities = (0.20, 0.15, 0.25, 0.20, 0.20)
```

| 模式 | 总采样比例 | 命令约束 |
| --- | ---: | --- |
| 站立 | 20% | vx=vy=yaw_rate=0 |
| 纯前进 | 20% | vx>0，vy=yaw_rate=0 |
| 平移 | 25% | 前后、左右或斜向运动，yaw_rate=0 |
| 原地转向 | 20% | vx=vy=0，yaw_rate 非零 |
| 边走边转 | 15% | 非零 XY 运动与连续 yaw rate 联合采样 |

平移的 25% 中，沿用源配置：60% 等概率采样纯后退、纯左移、纯右移，剩余 40% 保留任意 XY 方向。因此名义总配额分别为后退 5%、左移 5%、右移 5%、一般 XY 平移 10%。一般 XY 及边走边转还可能覆盖这些方向；这些是抽样分支配额，不是互斥的实际轨迹分类。

每个命令段保持 5 秒后直接重采样。20 秒回合在不中途终止时覆盖约四个命令段。比例是概率目标，有限环境数会波动；环境提前终止也会改变实际有效训练时长分布，需分别记录抽样次数和有效步数。

## 4. 后腿直立的首轮低速候选范围

下面是针对当前后腿直立任务的适配建议，**不是参考工程原值，也不是已验证的最优参数**。参考工程的纯前进最高 2 m/s、其他平移 1 m/s，不直接作为本任务起点。

| 参数 | 首轮候选 |
| --- | --- |
| 纯前进 vx | 0.08～0.20 m/s |
| 其他平移 vx | -0.10～0.12 m/s |
| 其他平移 vy | -0.08～0.08 m/s |
| 其他平移 XY 合速度 | 0.06～0.12 m/s |
| 原地转向绝对速度 | 0.12～0.30 rad/s |
| 边走边转 yaw rate | -0.30～0.30 rad/s |
| 重采样时间 | 5 秒 |
| heading_command | False，直接使用 yaw rate |
| 自动速度课程 | 首轮关闭 |

纯前进沿用参考的分段概率 60% / 15% / 25%，把三个区间适配为 `[0.08,0.12]`、`[0.12,0.16]`、`[0.16,0.20]` m/s，段内均匀采样。

源采样器对原地转向和边走边转共用 yaw 范围，因此首版两者都使用 ±0.30 rad/s；只有原地转向使用 0.12 rad/s 最小绝对值。边走边转可以抽到接近零的 yaw，这是原联合分布的行为。

首轮全范围已是低速，不再叠加原来的 30% / 0.35 倍低速子集，拟设 `low_speed_probability=0`。否则侧移上限 0.08 乘以 0.35 后低于 0.06 的运动最小速度，许多样本会被挤到同一个下界。速度范围扩展后，再独立评估是否恢复低速子集。

当前相位观测的移动判断使用 XY 模长 >0.04 m/s 或 yaw 绝对值 >0.08 rad/s；候选最小运动命令为 0.06 / 0.12，避免运动样本被当作静止。站立语义以模式及三轴零命令为准，不能直接照搬参考四足的 0.1 m/s 静止阈值，否则低速行走会被误判。

## 5. 奖励如何配合

当前 handstand 的 23 项公式和权重保持来源不变。本次不引入四足 `stand_contacts`、四脚站姿、四足步态奖励或新的转向奖励。

拟将当前按整次训练切换的两项开关，改为按环境、按当前命令模式执行：

- 站立：`contact`、`feet_clearance` 不计奖，允许两只后脚站稳。
- 所有运动模式，包括原地转向：启用这两项，继续引导后脚换步。
- 前脚悬空、前脚高度、直立方向、机身高度及其他已有项继续使用。
- 原地转向即使 XY 命令为零也属于运动；不能只按线速度判断站立。
- 不启用当前参考配置未开启的 Air Time，也不恢复原 V20 的额外前摆/载荷奖励。

这里的命令掩码是混合训练对现有阶段开关的适配，应明确记录为相对手撑直立参考实现的差异，不能称为原函数本来就有。

## 6. 坐标与动作采样

命令统一表示直立后的水平前进、侧移和竖直轴转向。当前直立机身 +X 朝上，水平前进使用机身 -Z；航向应使用现有 `wm.upright_heading`，不能把四足水平机身 +X 航向计算直接搬来。

直接 yaw rate 模式可以沿用参考五模式的 `heading_command=False`，避免零命令之后又被航向控制器改写。

关节动作维持：

```text
Actor(状态、速度命令) -> 12 维均值
训练：从高斯策略采样，初始标准差 1.0，之后学习
目标关节角 = 上游 default_joint_angles + 0.25 * action
PD：Kp=40，Kd=1；策略周期 0.02 秒
```

不能为每种命令模式另建一套关节动作库。阶段间或命令段间始终使用同一个策略，评估时按模式提供固定测试命令。

## 7. 训练顺序与参数

最终主训练建议为 `mixed`。不再把 15000 次零命令训练后接 15000 次固定直走作为唯一流程。

若随机初始化尚无法站稳，可先保留当前 balance 作为预热；达到独立评估的姿态、高度、前脚离地及稳定保持要求后，再接混合训练。预热长度由结果决定，不把固定迭代数当成已经学会的证据。进入混合后保留 20% 站立，避免行走训练完全失去停止样本。

混合训练先使用上表小范围，保持五模式比例。各模式稳定后，逐项扩大速度范围：提高纯前进上限不连带提高后退、侧移和转弯限幅。首版不从部署分支文档假定已有七模式课程或命令过渡实现，也不额外设计自动晋级机制。

PPO、PD、观测结构、初始直立姿态和现有域随机化暂按当前工程配置，先将命令分布作为独立实验因素。可先少量环境核对模式和命令，再使用默认 2048 环境、每环境 24 步 rollout；15000 次更新是预算，不是成功保证。

## 8. 必须同步的统计与评估

参考项目的 `Command/<mode>` 分组统计值得直接借鉴：

- 记录每模式抽样次数、实际有效控制步数、完整命令段比例。
- 记录 XY 向量速度误差、yaw 速度误差、姿态、高度、前脚触地、后脚接触与滑移。
- 站立检查平移和旋转是否都停止；原地转向检查方向与跟踪，不能要求前向位移为正。
- 后退、侧移和转弯不使用当前“初始朝向上的净前进位移”统一判定。
- 平移时的侧向速度应与 vy 命令比较，不能把所有侧向速度当成漂移。
- 统计左右后脚合格落地和交替，不把低速度误差等同于合格步态。
- 单独观察停止→运动、运动→停止、左右转向和方向反转的切换段。
- 按模式报告结果，避免一个总体均值掩盖某种命令一直失败。

当前评估脚本仅支持 balance/walk 和前向速度参数，统计主要面向直行。实施混合采样时必须一起适配命令输入、逐模式指标与验收，不能只改训练范围。

## 9. 一个已核对的低速奖励尺度问题

当前复制的速度奖励使用 `exp(-error² / 0.25)`。姿态高度门控打开、目标前进 0.12 m/s 时，静止的线速度得分仍为：

```text
exp(-0.12² / 0.25) = 0.94402748
```

这说明低速任务中“完全没走”的样本仍可能获得较高跟踪分，不能只靠总 reward 或该分数判断进步。本轮不自行修改公式、sigma 或权重，也不认定它是失败根因；先用实际误差、位移和步态证据验证，再对确认的问题单独做实验。
