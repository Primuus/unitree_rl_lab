## 训练示例

```bash
cd /workspace/ry_unitree_rl_lab
./ry_python.sh scripts/train_v20.py \
  --warm_start_actor checkpoints/warm_start_v11_model_40.pt \
  --num_envs 64 --max_iterations 10 --run_name independent_demo \
  --seed 42 --headless --device cuda:0
```

重复实验应更换 run_name，运行前确认目标 GPU 空闲。当前训练仍使用 Actor 热启动，Critic 和优化器重新初始化。

## 评估示例

将 checkpoint 指向本工程内需要评估的模型：

```bash
./ry_python.sh scripts/eval_v20.py \
  --checkpoint logs/rsl_rl/ry_unitree_go2_biped_walk_v20/2026-10-30_05-43-10_ry_train_export_demo_20261030/model_9.pt \
  --num_envs 4 --steps 1000 --speed 0.12 --seed 42 \
  --out logs/evaluation/independent_demo --headless --device cuda:0
```

本次迁移保持训练算法、奖励、观测、动作及已有镜像修正不变。评估器原默认速度仍为 0.2 m/s，上例显式使用与训练相同的 0.12 m/s。
